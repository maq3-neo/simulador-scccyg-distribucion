# Distribución del Simulador SCCCyG

Este repositorio contiene únicamente material público de distribución: página de descarga y manifiestos firmados. Los instaladores y sus firmas se publicarán como archivos de GitHub Releases. El código fuente de la aplicación y las claves privadas no pertenecen a este repositorio.

La beta pública todavía está en preparación. No se publica un manifiesto de actualización hasta contar con el instalador definitivo, su firma y su huella verificada.

Ruta prevista del manifiesto de respaldo: `simulador-scccyg/v1/latest.json`.
